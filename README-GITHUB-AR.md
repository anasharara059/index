# INDEX — شاشة تسجيل الدخول بالصورة الأصلية

تم استخدام الصورة المرفقة كما هي بدون إعادة توليد أو تعديل.
- `index.html`: النسخة الحالية مع الحفاظ على منطق Firebase/Google وتعديلات الحساب السابقة.
- `login-hero.png`: الصورة الأصلية المرفقة المستخدمة كواجهة تسجيل الدخول.
- الزر الحقيقي لتسجيل الدخول بـ Google يبقى تفاعليًا فوق زر الصورة.
- الحركة خفيفة وسلسة لمدة 10 ثوانٍ وتتكرر.
