طريقة التشغيل على Windows:
1) ثبّت Node.js LTS.
2) افتح Command Prompt داخل هذا المجلد.
3) شغّل: npm install
4) شغّل: npm start

بعد تشغيل التطبيق، عند الضغط على Start سيظهر العداد كنافذة صغيرة مستقلة فوق Chrome وفوق باقي البرامج.
يمكن سحب العداد، وإخفاؤه بزر ×. زر Pause يبقيه ظاهرًا باللون البرتقالي، وStop يخفيه.
يمكن لاحقًا إنشاء ملف تثبيت Windows باستخدام: npm run dist
